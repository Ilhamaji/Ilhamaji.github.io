## Decisions (Rulings)

- **Ruling: vitest pinned to 3.2.7, not latest (5.0.5).** Latest requires
  `@types/node >=22`; project pins `^20`. Bumping types across a Next 16
  upgrade is out of scope and risks the build.
  Cost if wrong: none — 3.2.7 supports the same API surface used.
- **Ruling: tests are static file-assertions, not DOM renders.** Adding jsdom
  + React Testing Library to a project with no test infra is a bigger change
  than the plan called for; the preloader bug is provable from source
  structure. Cost if wrong: a runtime-only regression could slip through —
  mitigated by the browser checks below.
- **Ruling: Rubik loads via `next/font/google`, not `@fontsource`.** Next
  self-hosts Google fonts at build time, so the static export still works.
  Gives automatic `display: swap` + preload for the body face with no extra
  package. Display faces (Permanent Marker, Caveat) use `@fontsource` because
  they are single-weight and cheaper to self-host directly.
  Cost if wrong: build-time font fetch for Rubik. Verified working.
- **Ruling: deleted 11 components up front, not spread across tasks.** They
  all imported the removed providers; keeping them broke the build after
  every step. Recoverable from git.
- **Ruling: hero uses its own entrance instead of `Reveal`.** `Reveal` is
  scroll-triggered; applying it above the fold made the first paint a
  half-drawn page (observed in a screenshot: faded buttons, invisible
  mascot). Hero content is the LCP element and renders at final opacity.
  Cost if wrong: hero lacks the scroll-in polish other sections have. It
  keeps a 0.4s opacity fade on the illustration only.
- **Ruling: `@fontsource` imports narrowed to `latin-*`.** Full-family
  imports shipped Cyrillic + Latin-Ext woff2 files nothing referenced.
  Measured saving: **503KB** (1,850KB → 1,347KB static export).
  Cost if wrong: non-Latin glyphs fall back to system font. Site copy is
  English-only, so no exposure.
- **Ruling: dropped Caveat weight 700.** Two `font-hand` usages, neither
  bold; the 700 files were dead weight (~115KB with subsets).

## Bugs found and fixed during execution

1. **Preloader deadlock (P0, pre-existing).** `root-provider` passed an inline
   arrow into a `useEffect` dependency array in `preloader.tsx`. Effect
   re-ran every render, so the progress bar reached 100% and never unmounted.
   Verified in-browser: page showed `WELCOME 100% INITIALIZING...` forever,
   `scrollHeight` stuck at 700px, zero content in the DOM. The live site was
   unusable. Fixed by deletion.
2. **Horizontal overflow (1518px at 1296px viewport).** Decorative `Blob` at
   `-left-24` escaped the section. Fixed with `-left-16` + `overflow-hidden`
   on the decoration layer. Now 1281 ≤ 1296.
3. **Detached mascot arm.** First attempt drew the waving arm as an isolated
   shape starting at x=292, outside the torso silhouette. Rendered as a
   floating purple stick. Rebuilt rooted at the shoulder (x=262).
4. **Mascot invisible on first paint.** Inherited the hero's `Reveal` delays
   (chained to 0.25s). Fixed with the hero entrance ruling above.
5. **Project tag badge overflowed its card** at 4-col width. Moved from
   `justify-between` row to a stacked column.
6. **GitHub card links were 33×33px** — below the 44px tap minimum. Raised to
   `h-11 w-11` (44px).
7. **Tape label rotated -6deg**, violating the design's own 2deg cap. Caught
   by the test suite, not by eye. Fixed to -2deg.
8. **Test path bug:** reveal-recipe exemption used a forward slash against
   Windows backslash paths, so the exemption never matched. Normalised.
